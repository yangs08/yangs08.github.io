AI Agent 流行了一年，竟然没有人真正讲透底层原理。这篇文章把 12 个最重要的概念压缩到一起，一口气讲完。

<!--more-->

## 1. Messages 数组 — AI 唯一的对话通道

AI 一来一回的对话，底层其实就是一个 `messages` 数组。你把参数装进去，里面包含你和 AI 来回的对话记录，大模型读完这个数组，接着写下一句回复。

空数组发过去，它一个字都说不出来。实际发送的是一个 JSON 格式的数组，包含了各种参数。这就是你和 AI 对话之间最底层的数据格式。

## 2. 上下文窗口 — AI 的"记忆"真相

告诉你一个真相：AI 根本没有任何记忆。它跟金鱼一样，每接一次请求都是重新开始。

所谓的"记忆"，就是把全部历史对话重新塞回去发给它。第一轮你说"我养了只猫叫小花"，AI 回复后问你猫的品种；第二轮你再问时，系统会把你之前所有的对话全部重新塞回去再发一次。AI 记得小花，完全是因为你把这段话又喂了它一遍。

**AI 的记忆 = 上下文窗口，没有别的。**

## 3. System Prompt — 让 AI 演一个角色

想让 AI 扮演特定角色？在请求前面加一句 system prompt 即可：

```
"你是一个抠门的老板"
```

同一个问题，加了 system prompt 后画风立刻变化。这就是系统提示词的威力 — 给 AI 加人设，它就按人设回复。

## 4. 思维链 (Chain of Thought) — 提高准确率的杀手锏

AI 算数字大概率是错的。比如 `12345 × 12345`，大模型完全是通过概率推测下一个数字，大概率会蒙一个答案。

**解法：加一句话 "请一步一步算"。**

就这一句提示词，可以让准确率暴涨 90%。AI 会按照步骤逐步计算，最终得出正确结果。这个技巧叫 **思维链提示 (Chain of Thought)**，千万别小看它。

## 5. Few-Shot 多样本 — 一个例子顶十句话

AI 不按你的格式输出？光说要求没用。直接给它两三个例子：

```
输入: xxx → 输出: xxx
输入: yyy → 输出: yyy
```

AI 一看就懂，格式立刻锁死。这叫 **Few-Shot 多样本提示**，是提示词工程的核心技巧，也是构建 Agent 的基础 — 没有稳定的输出格式，Agent 就会充满 bug。

## 6. 预填充 (Prefill) — 消灭废话

AI 总说 "好的，这是你想要的" 这些废话？在它要回答的位置，替它把第一个字提前写好：

```json
{
```

AI 没办法从头写，只能接着大括号往下续，直接吐出 JSON，一句废话都没有。这叫 **预填充**，是构建 Agent 的必备技能 — 你把格式定死了，它就没有自由发挥的空间。

## 7. 停止序列 — 让 AI 在该停的地方停

给 AI 设一个停止符号，比如 `Observation`，AI 写到这个词时立刻停止，把控制权交还给你。

**这是 Agent 循环的必备机制。** 如果不设停止序列，AI 可能会自己编造工具的返回结果 — 它会"幻想"工具执行了什么，导致 Agent 出现各种 bug。

## 8. Tool Use 协议 — AI 真的会调用工具吗？

**AI 根本不会调用任何工具。** 它永远只做一件事：吐字符串。

我们在大模型外部搭了一个框架，告诉它："你只要输出指定格式的 JSON，就能调用工具。" 比如想要北京天气，AI 输出一段 JSON 参数，外部框架收到后去调天气 API，把结果（26°C、晴）返回给大模型。

这就是 **Tool Use 协议** — 看似高深，原理极其简单。

## 9. RAG 检索增强 — AI 怎么懂你公司的知识？

AI 不懂你公司的内部信息。实际流程是：你提问之前，先用程序去文档库里查相关段落，把段落塞进 prompt 里，跟问题一起发给 AI。

**它不是"懂"，是"现读现答"。** RAG（Retrieval Augmented Generation）就是检索增强生成。

不过补充一点：随着 Claude、GPT 等模型的上下文窗口越来越大，模型自己就能读文档了，RAG 这条路未来怎么走，行业内还在分化。

## 10. ReAct 模式 — Agent 的自主决策

Agent 怎么自主决策？拆开看简单到离谱：**一个 while 循环 + 一个固定模板**。

模板就是：**思考 → 行动 → 观察**

AI 按这个格式输出，你的代码去识别、执行，再把结果返回。转几圈就能得出答案。这就是 **ReAct 模式** — Agent 自主运行的核心框架。

## 11. 自回归生成 — AI 为什么"幻觉"

AI 的本质是根据前面的字，猜出下一个最可能的字。它没有"知道"和"不知道"的概念，你问什么它都能答出一段话。

**幻觉不是 bug，是机制本身。** 这就是自回归生成。

应对方法：永远让 AI 给你依据，让它基于事实回答。比如问 "李白在 1985 年发表过什么著作"，AI 可能瞎编；但如果你说 "去网上查一下"，它会搜索发现李白已去世一千多年，从而给出正确回答。

## 12. Multi-Agent 编排 — 多个 AI 配合干活

让一个大模型当老板，接到任务后拆活，分配给子 Agent：

- 子 Agent A：查机票
- 子 Agent B：查酒店
- 子 Agent C：查行程

每个子 Agent 完成后，把结果汇总给主 Agent。这就是 **多 Agent 编排**。

## 总结

从 Messages 数组到 Multi-Agent 编排，这 12 个原理串起来就是 Agent 的全部灵魂：

| 原理 | 一句话总结 |
|------|-----------|
| Messages 数组 | AI 的对话载体 |
| 上下文窗口 | AI 的"记忆"就是重放历史 |
| System Prompt | 给 AI 加人设 |
| 思维链 CoT | "请一步一步算" 提高准确率 |
| Few-Shot | 给例子比说十句话管用 |
| 预填充 Prefill | 帮 AI 开头，消灭废话 |
| 停止序列 | 让 AI 在该停的地方停 |
| Tool Use | AI 不调工具，只吐字符串 |
| RAG | 现查现答，检索增强 |
| ReAct 模式 | 思考→行动→观察循环 |
| 自回归生成 | 幻觉是机制，不是 bug |
| Multi-Agent | 一个老板多个小弟 |

少一个都不行。Agent 就是这些小技巧的组合 — 把它们全部合并到一起，就能做出真正的 Agent。
